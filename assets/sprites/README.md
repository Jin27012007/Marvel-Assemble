# Marvel Assemble — recursos visuais iniciais

A folha de sprites fornecida pelo criador do projeto foi preparada localmente em PNG com transparência e dividida em recortes retangulares aproximados por categoria.

O pacote completo para download inclui a folha original, a versão com o fundo branco removido e os recortes: intro, idle, walk, run, jump, flight, repulsor_basic, dual_shot, charged_attack, unibeam, missiles, air_attack, energy_shield, power_pose, damage, defeated, get_up, slide, extras e effects.

**Observação:** os recortes são regiões aproximadas da folha; ainda não são frames individuais limpos e alinhados. A folha contém rótulos e efeitos junto dos sprites. Antes de integrar animações no jogo, será preciso separar cada frame, conferir a transparência e padronizar dimensões. O pacote binário ZIP não pode ser enviado diretamente pela API de arquivos de texto deste conector; por ora, este arquivo registra a organização dos assets no repositório.
